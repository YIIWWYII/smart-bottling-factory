# 平台岗服务包

这是可运行的平台项目，模拟数据默认由平台自身生成。包内不含本机数据库、账号、Coze 容器、适配模型、机械臂 IP 或上传文件。此演示包用于局域网服务交接，启动前不要连接真实机械臂。

## 第一次使用前安装什么

1. 安装 Windows x64 的 Node.js 24 LTS。它负责安装网页依赖和启动平台业务服务；安装后重新打开命令行，执行 `node --version`，主版本号应为 24 或更高。
2. 安装 Docker Desktop for Windows，并在设置中启用 WSL 2 后端。打开 Docker Desktop，等到界面显示 Engine running。Docker 负责运行平台使用的 MySQL 数据库，学生不需要单独下载或配置 MySQL。
3. 首次启动需要联网：脚本会从项目锁定文件执行 `npm ci`，并由 Docker 拉取 `mysql:8.4` 镜像。之后再次启动会复用已下载的依赖和数据库卷。

如果电脑没有管理员权限，先让管理员完成 Node.js 和 Docker Desktop 安装；项目本身不需要管理员权限。

## 启动平台

电脑需要 Node.js 24 和 Docker Desktop。双击 `start.cmd` 后，脚本会依次检查 Node.js、Docker 命令和 Docker 引擎；任何一项缺失都会给出下一步提示。检查通过后，首次启动会创建 `.env`、拉取 MySQL 8.4、安装锁定的网页依赖，再启动本地视觉、固定问答备用和网页。数据库端口是本机 53307。保持启动窗口打开。

浏览器在平台电脑打开 http://127.0.0.1:5174/。其他岗位访问 http://平台电脑局域网IP:5174/。Windows 防火墙只需允许 TCP 5174 的专用网络入站。数据库端口仅绑定本机，不向局域网其他电脑开放。

## 接入岗位服务

进入「工程管理 → AI 配置」。在「AI 视觉 → 视觉服务」填写视觉岗的 http://视觉电脑IP:8093，把备用地址设为 http://127.0.0.1:18093（从旧包升级时，若备用地址仍为 8093，请修改后保存），保存并测试。在「AI 助手 → Coze 智能体」填写智能体岗的 http://智能体电脑IP:8889、实际 Bot ID 和令牌（使用固定回复联通时改填 8887 和演示凭证），保存并测试。已有本机 Coze 时，可以把它作为备用；本包默认的 127.0.0.1:8887 只返回固定问答，不能代替 Coze 工具流程。远端无法连接时切换一次，已经发出的智能体请求不会因超时自动重发。

给测试岗平台地址 http://平台电脑IP:5174/。如要让已发布的 Coze 查询平台设备或生成待确认提案，另给智能体岗工具回调地址 http://平台电脑IP:8094 和本包首次启动生成的 config/platform-agent.json 中的 toolToken，并仅对比赛局域网放行 TCP 8094。无需把数据库端口交给对方。

USB 摄像头插在平台电脑。用 http://127.0.0.1:5174/ 进入「AI 视觉 → 相机接入」，点「搜索本机摄像头」，授权后选择机位并保存。实际画面继续播放，使用预置结果展示检测。无需 Python 或 OpenCV 采集服务。

各电脑必须在同一可信局域网。远端服务端口需允许专用网络入站。地址写服务电脑的 IPv4，不能把 127.0.0.1 当成别人的电脑。

## 运行边界

四路结果是演示素材，平台默认工位数据为模拟数据。本地智能体备用只提供固定问答；要展示 Coze 的知识库、告警报告和人工确认，需要接入原来配置好的真实智能体。

## 关闭演示服务

停止平台终端即可停止网页和业务接口；数据库需要在平台工程目录运行：

    docker compose -p bottleworks-handoff -f docker-compose.demo.yml down

不要执行 `down -v`，否则会删除演示数据库卷。
