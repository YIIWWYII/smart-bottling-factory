# 视觉岗服务包

提供四路视觉流程的接口模拟服务，可交给平台岗和测试岗直接调用。OpenCV 打码、YOLO、PatchCore 和联合检测都返回预制素材与固定正常/缺陷结果；没有安装 OpenCV、没有真实推理，也不需要微调模型。

## 第一次使用

这个服务是视觉岗提供给平台岗、测试岗调用的“固定结果演示服务”。它不安装 OpenCV，也不加载 YOLO、PatchCore 权重；四路图片和处理结果已经随包提供。电脑只需要安装 Node.js 24 LTS（Windows x64）。安装后重新打开命令行，执行 `node --version`，主版本号应为 24 或更高。

## 启动

电脑已安装 Node.js 24 后，双击 `start.cmd`。脚本会先检查 Node.js，再启动服务。服务默认监听 0.0.0.0:8093，健康检查地址是 `http://本机局域网IP:8093/health`。运行 `ipconfig` 查看本机局域网 IPv4 地址，并用浏览器打开健康检查地址。若其他电脑无法访问，在 Windows 防火墙中允许 TCP 8093 专用网络入站。

如果窗口显示 Demo vision is already running，沿用窗口中的地址即可。平台岗包的本机备用视觉服务使用 18093，和本包同时启动时不占用 8093。

把这个地址交给平台岗和测试岗。接口为 GET /health，以及 POST /opencv、/yolo、/patchcore、/inspect。请求 JSON 见测试岗服务包中的视觉请求示例.json；caseId=normal 返回通过，caseId=defect 返回不合格。图片使用随包预制素材，上传帧用于记录请求输入，不用于实际算法运算。

不要把服务开放到公网。对接时填写服务电脑的局域网 IP，不能填写对方电脑的 127.0.0.1。
