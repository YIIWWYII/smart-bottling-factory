# 智慧装瓶工厂生产后端

这是 Spring Boot 生产业务服务的内置说明页。服务默认运行在 `8088`，接口前缀为 `/hdc/api`。

## 服务职责

- 为数字展板、工位终端和后台管理端提供认证、生产、设备、产品、质量、异常、物流和仓储接口。
- 使用 MySQL 持久化生产事实、命令、审计和配置，并通过 WebSocket 推送实时状态。
- 接收边缘设备标准化遥测和执行回执；具体传感器、PLC、机械臂和 AGV 协议由边缘层负责。
- 为独立 AI 中枢提供只读事实、视觉识别结果和字段级命令意图接口。

## 运行地址

```text
HTTP:      http://<backend-host>:8088/hdc/api
WebSocket: ws://<backend-host>:8088/hdc/api/dataScreen/{groupId}
```

真机和模拟器不能使用 `localhost`，应填写运行后端电脑在局域网中的地址。

## 安全边界

设备命令必须经过身份、角色、工位范围、参数范围、联锁、幂等和审计校验，并等待边缘层回执。HTTP 请求成功只代表后端接受了请求，不代表设备已经执行成功。

普通 AI 助手问答没有设备命令副作用。AI 产生的字段级命令意图仍需经过本服务的安全闸口。

数据库初始化、启动命令、演示账号和完整联调步骤见仓库根目录 [ONBOARDING-DEPLOYMENT.md](../../../../../../../ONBOARDING-DEPLOYMENT.md)。跨模块接口定义见根目录 `contracts/`。
