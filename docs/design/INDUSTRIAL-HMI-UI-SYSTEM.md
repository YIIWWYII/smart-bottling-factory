# 瓶装产线工业 HMI UI/UX 系统

## 设计目标

三类鸿蒙前端共享一套工业控制室视觉语言，但承担不同任务：

- 数字展板：让参观者和管理者先看懂整条产线，再进入某个工位。
- 工位终端：让现场人员快速确认本站状态、设备、物料、质量门，再执行受控操作。
- 后台管理：让管理员处理异常、治理 AI 和知识、查看审计，不重复数字展板动画。

设计参考了 SCADA/HMI 数据密集型界面、ISA-101 相关 HMI 层级原则、工业数字孪生控制室的主视图布局，以及 ArkUI 的响应式布局能力。

## 视觉方向

名称：蓝白工业控制室（Blue Steel Control Room）。

- 导航锚点：深钢蓝 `#102A3B`。
- 主操作：工业蓝 `#146A9F`。
- 数据强调：冷青蓝 `#2E8ABF`。
- 工作区：冷灰白 `#E9EFF3`，内容面 `#FFFFFF`。
- 正常：绿色 `#1F7A57`，等待：琥珀 `#B66A0A`，异常：红色 `#B23C43`。
- 阴影和渐变不作为主要装饰，面板使用细边界和左侧状态线建立层级。
- 状态必须同时显示文字、圆点和颜色，不能只用红绿区分。

## 排版和空间

- 基线间距：4px；常用间距：8、12、16、20、24px。
- 字号：9px 辅助标签，10px 说明，12/14px 正文，17/19px 区块标题，23/28px 页面标题。
- 页面只保留一个主标题和一个主任务区域。
- 信息区不使用无限自动换行；长列表放进明确的 `Scroll`，主视图使用稳定高度。
- 卡片只用于独立的重复对象、详情和需要边界的工具，不把整页每块内容都做成浮动卡片。
- 复杂详情采用“列表左侧、详情下方或右侧”的固定顺序，避免选中对象后页面跳动。

## 页面树

### 数字展板

```text
FactoryOverview
|- 顶栏：产线身份 / 后端在线 / 数据更新时间
|- 生产流程：九个工位卡片，点击进入 StageDetail
|- 关键运行指标：投入、WIP、完成、剔除、待处理、通过率
|- 运行摘要：生产质量 / 设备约束 / 物流仓储 / 异常 / 产品追踪

StageDetail
|- 顶栏：返回总览 / 当前工位 / 前后工位
|- 主视图：2D 平面图或 3D 场景，按需开关、暂停、状态着色
|- 视图工具栏：2D、3D、状态颜色、布局编辑、暂停恢复
|- 设备与物料：可选中，显示稳定实体信息
|- 质量门与异常影响：只读解释，不放现场控制按钮
```

### 工位终端

```text
Workstation
|- 顶栏：终端身份 / 实时通道 / 数据来源
|- 工位选择：工位名称 / 状态 / 简介 / 进入动作

StageDetail
|- 顶栏：工位身份 / 快照版本 / 上下工位
|- 主视图：本站 2D 或 3D 动画
|- 本站快照：状态、WIP、缓冲、报警、数据源
|- 设备与传感器：选择对象查看读数
|- 物料与质量门：追踪号、瓶型、质量状态
|- 控制工作区：参数调整、动作按钮、联锁、二次确认、命令回执
|- 上下游影响：控制动作可能影响的过程
```

### 后台管理

```text
AdminConsole
|- 侧栏分组：运营监控 / 现场资产 / AI 治理 / 系统管理
|- 顶栏：当前页面 / 数据源 / 当前用户
|- 页面工具栏：搜索 / 筛选 / 刷新
|- 页面主体：指标或列表
|- 详情区：选中对象的可追踪字段和审计结果
```

## 交互边界

- 展板只导航和查看，不直接发送控制命令。
- 工位端可以提出参数和动作命令，但必须经过角色、联锁、后端安全闸口和二次确认。
- 后台负责配置、治理、异常处置和审计，不能把 AI 助手当作控制命令入口。
- 2D 与 3D 使用同一份实时快照和实体 ID；切换视图不改变业务选择。
- 关闭视图只停止 ArkWeb/Three.js 渲染，不停止实时数据刷新。
- 暂停视图只冻结画面，恢复后跳到当前快照，不回放历史动画。

## 验收标准

- 首屏 3 秒内能回答“产线是否运行、哪里异常、如何进入某个工位”。
- 工位端 3 秒内能回答“本站处理什么、设备是否在线、当前产品是什么、是否允许调整”。
- 后台 3 秒内能找到“异常、设备、物料、AI 配置、知识审核、审计”。
- 所有可点击对象都有状态反馈和明确的下一步；不可用按钮必须解释原因。
- 三端静态校验和 DevEco debug 构建必须通过；有模拟器时再做安装、启动和画面验收。
