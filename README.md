# 瓶安智慧产线协同系统

当前演示由网页平台和 HarmonyOS 应用组成。网页平台提供产线展示、工位终端、工程管理、设备通信、视觉接入和 Coze 智能体接入；鸿蒙应用通过 ArkWeb 加载同一套网页，打开应用即可进入工位终端。

## 下载与部署

从零部署、数据库配置、启动、鸿蒙导入与打包、后续更新及常见问题，统一见 **[项目交接与部署说明](ONBOARDING-DEPLOYMENT.md)**。

请完整克隆仓库，保留以下目录关系；只下载网页目录不能构建鸿蒙应用。

| 内容 | 相对仓库根目录的位置 |
| --- | --- |
| 当前网页平台及 Node.js 业务服务 | work/industrial-design-demo/ |
| 当前鸿蒙外壳工程（DevEco 打开此目录） | apps/workstation-terminal/BottlingFactoryTerminal/ |
| 鸿蒙工程引用的共享模块 | packages/harmony-assistant/harmonyassistant/ |

网页平台需要 Node.js 24 和 MySQL。鸿蒙工程需要 DevEco Studio 和工程指定的 HarmonyOS SDK 6.1.1(24)。平台启动后，在电脑浏览器打开 http://127.0.0.1:5174/；鸿蒙模拟器默认访问 http://10.0.2.2:5174/#station，实体设备使用服务电脑的局域网地址。

初次运行会创建业务表和初始演示数据。设备通信参数可在构建应用后配置，留空不阻止应用构建。数据库、访问令牌、签名证书、Coze 容器及模型权重需要在使用电脑单独配置或从迁移包恢复。

## 功能与资料

- 网页平台：产线 2D/3D 展示、生产任务、工位信息、参数调整、告警和设备资产管理。
- 机械臂：MG400 TCP 通信、反馈展示、模型关节映射、轨迹工程登记与选择、运行状态和速度比例。
- 视觉：多机位图像接入和检测结果展示；真实检测需要单独部署视觉服务及模型。
- 智能体：对接已发布的 Coze 智能体，支持问答、设备点选问答、告警报告和需要确认的写入提案。
- 模型及资源位于网页工程 public/，平台配置位于 config/，平台技能位于 skills/。

当前鸿蒙入口直接加载网页。应用保留“原生工位”按钮作为旧原生界面的入口，该原生界面使用另一套后端接口，不是当前网页平台部署的前置条件。
