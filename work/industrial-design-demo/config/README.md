# 平台配置文件

`device-capabilities.json` 保存设备参数定义和中文设备名称，包括参数编号、类型、单位、允许范围、默认值、角色与确认要求。`alarm-rules.json` 保存告警指标、阈值、所属工位、模型部件匹配与提示。前后端通过原有 JS 模块引用同一份定义，告警判定代码仍在 `src/alarmRules.js`。

这是静态配置与逻辑分离，不是运行时热更新。正式发布时修改这些 JSON 后须运行测试、重新构建前端并重启服务，保持前后端版本一致。开发服务器可能自动重载，修改前应停止演示操作。已有数据库中的设定值不会被新的默认值直接覆盖。

不要改动已有参数 ID、工位编号或设备编号来更名；它们关联数据库、映射和模型。需要更名时优先修改显示名称。参数允许范围与告警阈值含义不同，不能相互替代。现有阈值用于平台演示，不是经认证的现场安全规则。

修改后运行：

```
node --test process-config.test.mjs alarm-rules.test.mjs
npm run build
```

实时业务数据、连接配置仍由 MySQL 管理；Skill 位于 `skills/`；模型、图片仍独立存放。旧 `assistant-skills.json` 仅用于迁移，不是当前技能编辑入口。
