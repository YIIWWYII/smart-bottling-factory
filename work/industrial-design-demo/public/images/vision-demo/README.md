# 四路检测素材

normal 为正常瓶，defect 为异常瓶。每套有四个机位（top、side-0、side-120、side-240），每个机位分别保存 original 原图、opencv 白色条码遮罩图、yolo 检测框图、patchcore 异常热力图，共32张黑底图片。

异常瓶依据提供的照片重建标签表面与贴图，包含上部污渍、侧后污渍、标签破口和局部褶皱。四机位图片来自 Blender 渲染；标框、白色遮罩与热力图用于离线演示，未执行真实模型推理。无缺陷视角保持正常，不随整瓶结论统一标成缺陷。

工位终端统一使用“四路联合检测”，在其内部切换实际、模拟画面。小菱形按钮持续切换正常和异常样本，点击“开始检测”时固定本轮选择。实时预览持续运行；原始画面取本次摄像头或三维渲染的采集帧，处理结果取本目录或后台上传的素材。

配置入口：工程管理 → AI配置 → AI视觉 → 视觉服务 → 高级设置 → 离线素材与回放。上传后保存，从下一轮开始使用。真实模式沿用真实视觉服务。
