# 四路模拟检测素材

平台默认使用纯模拟检测。正常瓶 normal、异常瓶 defect 各一套，每套四个机位：top、side-0、side-120、side-240。每个机位包含 original 原图、opencv 白色遮罩图、yolo 缺陷框图和 patchcore 热力图，共32张黑底图片。

异常瓶根据提供的照片重建标签表面与贴图，包含上部污渍、侧后污渍、标签破口和局部褶皱。无缺陷机位保持正常。所有素材用于演示处理流程，不运行实时推理。

操作：工位终端 → 外观检测或二次检测 → 四路联合检测 → 点击开始检测。小菱形按钮持续切换正常、异常。模拟瓶体持续运行，原始画面保存当次三维截帧，其余三栏显示对应处理图。

模型、贴图和图片随仓库提供。新电脑无需摄像头、Python、OpenCV或视觉服务；旧数据库关闭设置和失效上传路径会自动恢复到可用的模拟默认值。需要更换图片时，打开工程管理 → AI配置 → AI视觉 → 高级设置 → 模拟检测素材。
