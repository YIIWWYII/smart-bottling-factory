# 常见异常与辅助设施联动

模拟入口：工位终端的“异常演示与设施联动”；数字展板工艺页可查看全部场景。仅模拟模式且具备对应工位控制权限可触发。

电控柜超温：柜内温度 ≥ 60 °C触发。联动：启动柜体散热风扇。恢复：回落至 50 °C 自动退出联动。

料液温度过高：罐内温度 ≥ 32 °C触发。联动：打开冷却水阀并启动循环泵。恢复：回落至 28 °C 自动退出联动。
储液罐液位过低：储液罐液位 ≤ 20 %触发。联动：停止供液泵，暂停灌装取液。恢复：排除异常后人工复位；阈值恢复不等于设备自动重启。
储液罐液位过高：储液罐液位 ≥ 90 %触发。联动：关闭进液电磁阀。恢复：排除异常后人工复位；阈值恢复不等于设备自动重启。

输送带堵料：堵料持续时间 ≥ 5 s触发。联动：停止上游送料并升起挡瓶器。恢复：排除异常后人工复位；阈值恢复不等于设备自动重启。
输送电机过载：额定电流占比 ≥ 120 %触发。联动：驱动保护停机，停止关联送料。恢复：排除异常后人工复位；阈值恢复不等于设备自动重启。

单瓶灌装量不足：灌装量偏差 ≤ -2 %触发。仅记录告警，不联动其他设施。

AGV 前方有障碍：最近障碍距离 ≤ 0.5 m触发。联动：车辆保护停车，开启声光提示。恢复：排除异常后人工复位；阈值恢复不等于设备自动重启。

## 模型

Blender 5.2.1 制作，源文件 safety-facilities.blend，五个 GLB 位于 public/models/safety-facilities。FanRotor、CoolingValve、InletValve、LiquidLevel、StopperGate 为运行时驱动节点；曲线管路、护网、旋转叶片和液位刻度独立建模。原场景对象保留。

## 执行与边界

演示传感器与正常工序遥测分开；超温模型按规定速度降温，属于模拟响应，不是热力学计算。保护期间暂停相关动画与产量推进；排除异常后保护保持，人工复位才解除。告警触发/恢复、设施执行/完成各自记录至工位及产线日志。真实模式接口拒绝触发，不发送实体设备命令。AGV 调度任务若已暂停仍需在物流界面显式恢复。
