# 设备阈值与三维告警说明

版本：演示规则 v1。规则源为 src/alarmRules.js，网页与后端共用。

## 瓶体预处理 · 告警规则（演示）

演示规则，不作为真实生产安全标准。达到上限或低于/等于下限触发，严重优先；回到正常区间恢复。离线时终止判定，不代表恢复正常。只在触发、等级变化及恢复时写日志。告警不自动下发停机命令。

输送速度（模拟设定值）：预警 ≤ 80 或 ≥ 160 mm/s；严重 ≤ 65 或 ≥ 175 mm/s。检查输送节拍与积瓶情况。

水洗时间（模拟设定值）：预警 ≤ 10 或 ≥ 40 s；严重 ≤ 7 或 ≥ 55 s。复核清洗覆盖与喷淋时间。

风洗时间（模拟设定值）：预警 ≤ 8 或 ≥ 30 s；严重 ≤ 6 或 ≥ 40 s。检查瓶内残液与气路。

清洗温度（运行读数）：预警 ≤ 35 或 ≥ 55 °C；严重 ≤ 30 或 ≥ 60 °C。检查清洗温度与加热状态。

## 三维与日志

橙色预警、红色严重；部件定位光圈、灯及文字同时变化。停机不代表故障，告警不自动改变设备运行命令。真实设备只根据有效遥测评估运行读数，设定值演示规则不套用于实机。

局部模型的未保存参数仅作预演，不进入业务日志。保存后由服务端判断，同一告警持续期间不重复写入；等级变化、恢复和离线/模式切换导致的判定结束分别记录。产线日志包含全线事件，工位日志按工序筛选。

在工程管理的设备资产 → 查看设备中可查看规则。九份规则文档同步存入当前文档库，供资料查询使用。


## 四路视觉检测监看

视觉工位采用顶部 1 台与侧面 0°、120°、240° 共 4 台相机。网页复用原 Blender 相机网格，在运行时调整机位；原始 GLB 文件未覆盖。顶部为 VIS-TOP-01，侧面为 VIS-SIDE-01/02/03，各自具有 cameraState 控制。旧底部相机退出当前控制目录，历史日志保留。

工位终端支持四路同屏及单路查看，画面由同一检测模型实时渲染，照明设定影响画面亮度；暂停某一路不会启动或暂停整条工位。模拟画面不是现场视频或缺陷识别结果。真实模式未接视频流时明确提示未接入。
