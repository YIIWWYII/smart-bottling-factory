# 跨端功能矩阵

本表是总设计边界。每一项前端功能都必须有后端数据源或命令接收端；“无”表示该端不应实现，避免重复。

| 业务域 | 数字展板 | 小屏终端 | 后台管理 | AI 协同端 | Spring Boot 后端 |
| --- | --- | --- | --- | --- | --- |
| 身份与权限 | 预置展板身份，只读 | 未登录可只读；操作前登录 | 强制登录、RBAC、用户管理 | 强制登录；问答和上传按权限开放 | 客户端身份、会话、角色和接口鉴权 |
| 整线拓扑 | 展示九工序和流向 | 工位选择与本站关系 | 管理产线、工位和设备档案 | 决策上下文中的工位/设备关系 | 提供拓扑、归属和版本 |
| 工位实时状态 | 工位卡片和详情 | 当前工位主页面 | 运营监控和历史查询 | 展示当前 AI 决策关联工位 | 生成唯一 `StageSnapshot` 并推送 |
| 设备遥测 | 只读状态和关键读数 | 本站详细遥测 | 查询、维护和历史 | 展示 AI 使用的上下文快照 | 接收、校验、缓存和持久化 |
| 2D/3D 可视化 | ArkWeb 本地 Three.js | ArkWeb 本地 Three.js | 无沉浸动画 | 仅决策/设备动画用 ArkWeb 本地 Three.js | 提供动作、速度、位置和状态数据 |
| 生产任务 | 计划/实际摘要 | 本站工单、批次和目标 | 创建、排产、暂停和追溯 | 只显示决策关联任务 | 持久化工单并驱动状态 |
| 产品追踪 | 全局搜索和结果 | 本站在制品和质量事件 | 全量查询、筛选和导出 | 显示识别瓶型、产品和证据 | 维护追踪链、箱码、AGV 和库位 |
| 质量门 | 只读结果和依据 | 本站当前值和放行状态 | 规则版本、审批和追溯 | 显示 AI 决策引用的质量约束 | 统一计算最终结果 |
| 运行参数 | 只读当前值和来源 | 在批准范围内人工调整 | 管理模板、版本和允许范围 | 展示 AI 拟修改/跳过字段 | 维护字段值、版本、所有权并最终校验 |
| 人工覆盖锁 | 只读摘要 | 创建/释放本人有权处理的锁 | 查询、强制释放和审计 | 明确显示 AI 无法修改的字段和原因 | 强制执行字段锁、原子组和乐观锁 |
| 安全阈值 | 只读判定结果 | 只读 | 版本化配置、审批和回滚 | 只读显示校验依据 | 持久化并强制联锁 |
| 设备控制 | 无 | 发起本站人工命令并等回执 | 维护/应急/跨工位操作 | 无；普通问答和界面按钮不得控制设备 | 鉴权、联锁、下发、超时、回执和审计 |
| AI 参数决策 | 显示摘要 | 显示本站建议和执行结果 | 策略、审批和完整审计 | 完整展示识别、RAG、校验、补丁、锁和回执 | 汇总上下文、调用 AI、最终校验并创建命令 |
| AI 问答 | 无 | 无 | 可查审计，不做聊天主界面 | 多轮问答、来源引用和历史 | 会话、鉴权、流式转发和留痕 |
| 资料提交 | 无 | 无 | 可代提交和管理全部资料 | 上传资料并查看审核进度 | 隔离存储、解析、去重和创建审核任务 |
| 资料审核 | 无 | 无 | 审核、拒绝、撤销、发布和冲突处理 | 只显示状态和意见，不提供批准 | 审核状态机和权限校验 |
| 知识入库 | 无 | 无 | 查看发布与索引结果 | 收到 `INDEXED/REJECTED` 通知 | 批准后写 MySQL/文档存储并触发向量化 |
| 异常处置 | 展示异常 | 本站确认、剔除/暂停等授权动作 | 跨工位返工、缓冲和关闭 | 解释异常及相关决策，不处置 | 异常状态机和影响计算 |
| AGV/仓储 | 全局运力和库存摘要 | AGV/入库工位操作 | 调度、库存、库位和安全配置 | 只在相关问答中引用 | 任务、遥测、库存和安全事务 |
| 模拟演示 | 只显示中央模拟结果 | 只读模拟；不伪造控制 | 启停和重置模拟场景 | 使用同一模拟决策链并标明来源 | 唯一模拟时钟和场景引擎 |
| 报表与审计 | 实时 KPI | 本站最近操作结果 | 报表、操作、命令、AI 和知识审计 | 查看本人问答/提交/相关决策 | 聚合报表并持久化审计 |

## 不得越界

- 数字展板不产生业务写操作；拖拽布局、暂停、着色属于本地显示偏好。
- 小屏调整的是获批范围内的运行设定值；人工修改后形成字段级覆盖锁，AI 不得覆盖。
- 后台管理负责模板、审批、全局调度、知识审核、历史和审计，不重复现场 HMI 或 AI 聊天主界面。
- AI 协同端负责解释、问答、资料提交和审核进度，不审核自己的资料、不直连数据库、不下发设备命令。
- 后端是状态、参数所有权、审核和判定真相源。AI、硬件、四前端都不能绕过后端改变业务状态。
