# 跨端功能矩阵

本表是总设计边界。每一项前端功能都必须有后端数据源或命令接收端；“无”表示该端不应实现，避免重复。

| 业务域 | 数字展板 | 小屏终端 | 后台管理 | Spring Boot 后端 |
| --- | --- | --- | --- | --- |
| 身份与权限 | 使用预置展板客户端身份，只读 | 未登录可只读；操作前用操作员账号登录 | 用户登录、会话、RBAC、用户管理 | 客户端身份、用户会话、角色和接口鉴权 |
| 整线拓扑 | 展示九工序、全局状态和流向 | 只显示工位选择与当前工位关系 | 管理产线、工位、设备档案和启停配置 | 提供拓扑、设备归属和版本 |
| 工位实时状态 | 工位卡片和工位详情 | 当前工位主页面，内容与展板一致 | 运营监控和历史查询 | 生成唯一 `StageSnapshot` 并推送变化 |
| 设备遥测 | 只读状态、来源、关键读数 | 只读本站设备详细遥测 | 查询、筛选、维护和历史 | 接收 MQTT/HTTP，校验、缓存、持久化 |
| 2D/3D 可视化 | ArkWeb 本地 Three.js，全局进入工位 | ArkWeb 本地 Three.js，当前工位 | 无沉浸动画 | 提供动作、速度、位置、状态数据，不渲染 |
| 生产任务 | 展示计划/实际和进度摘要 | 展示本站当前工单、批次和目标 | 创建、排产、暂停、结束和追溯 | 持久化工单并驱动产品创建与工序状态 |
| 产品追踪 | 全局搜索、工位在制品和结果 | 本站在制品、当前产品和质量事件 | 全量查询、筛选、详情和导出 | 维护 `traceCode`、事件链、箱码、AGV 和库位 |
| 质量门 | 只读结果、依据和异常 | 当前值、标准、放行状态；按权限请求处置 | 规则版本、阈值审批、失败追溯 | 统一计算质量门，前端不得自行作最终判定 |
| 运行参数 | 只读当前配方/参数来源 | 在批准范围内调整本站运行设定值 | 管理参数模板、版本、审批和允许范围 | 返回设备能力并对每条命令最终校验 |
| 安全阈值 | 只读当前版本和判定结果 | 只读，不允许现场任意修改 | 版本化配置、审批、发布、回滚 | 持久化阈值并用于安全联锁 |
| 设备控制 | 无 | 发起本站允许命令并等待回执 | 维护/应急/跨工位操作及审批 | 鉴权、联锁、幂等、下发、超时、回执和审计 |
| 异常处置 | 展示异常和影响范围 | 本站确认、剔除/暂停等被授权快捷动作 | 跨工位策略、返工、缓冲、关闭和复盘 | 异常状态机及上下游影响计算 |
| AI 决策 | 展示当前建议来源和执行状态摘要 | 查看建议、校验依据；按权限确认应用 | 审批、审计、知识版本和效果追踪 | 调用 AI 外部端口，数据库校验后走命令安全门 |
| AGV 物流 | 全局运力、任务、速度和避障 | AGV 工位任务、速度上限和调度请求 | 任务调度、优先级、车辆和历史 | 任务分配、遥测、冲突处理和持久化 |
| 仓储管理 | 仓区安全和库存摘要 | 入库工位、库位建议和安全处置请求 | 库存、库位、入出库、盘点和安全配置 | 箱级库存、库位状态、安全遥测和入库事务 |
| 模拟演示 | 只显示中央模拟结果和明显来源 | 只读模拟；禁止伪造控制成功 | 选择、启动、停止、重置演示场景 | 唯一模拟时钟和场景引擎，统一驱动三端 |
| 报表与审计 | 只展示实时 KPI | 查看本站最近操作结果 | 报表、操作审计、命令审计、AI 审计 | 聚合报表并持久化不可抵赖审计记录 |

## 不得越界

- 数字展板不产生业务写操作；拖拽布局、暂停、着色属于本地显示偏好。
- 小屏调整的是“获批范围内的运行设定值”，不是安全阈值、规则版本或用户权限。
- 后台管理不重复现场 HMI；它管理模板、审批、全局调度、历史和审计。
- 后端是状态和判定真相源。AI、硬件、三前端都不能绕过后端直接改变业务状态。
