# 跨端功能矩阵

本表是总设计边界。生产事实和设备命令归 Spring Boot，视觉、决策、问答和知识归 AI 中枢；“无”表示该端不应实现。

| 业务域 | 数字展板 | 小屏终端 | 后台管理 | Spring Boot 生产后端 | AI 中枢 |
| --- | --- | --- | --- | --- | --- |
| 身份与权限 | 预置展板身份，只读 | 未登录可只读；操作前登录 | 强制登录、RBAC、用户管理 | 客户端身份、会话、角色和接口鉴权 | 校验令牌/客户端范围，不另建用户体系 |
| 整线与工位 | 九工序总览和详情 | 当前工位和上下游 | 管理产线、工位和设备档案 | 拓扑、快照和版本真相源 | 只读查询作为决策/问答上下文 |
| 设备与遥测 | 只读状态和关键读数 | 本站详细遥测 | 查询、维护和历史 | 接收、校验、缓存和持久化 | 实时问题与决策时只读查询 |
| 2D/3D | ArkWeb 本地 Three.js | ArkWeb 本地 Three.js | 无沉浸动画 | 提供动作、速度、位置和状态 | 接收被选设备/物料语义上下文 |
| 共享助手宿主 | `DISPLAY` 适配器、挂载点、稳定选择 ID | `WORKSTATION` 适配器、挂载点、稳定选择 ID | `ADMIN` 适配器、挂载点、稳定选择 ID | 仅提供经鉴权生产事实 | 实现唯一 HAR、会话/RAG/流式服务 |
| 生产与追踪 | 计划、质量、产品和物流摘要 | 本站工单、在制品和质量事件 | 工单、追踪、报表和审计 | 维护状态机、追踪链和库存 | 解释实时状态和文档依据 |
| 参数与人工锁 | 只读摘要 | 在批准范围内人工调整/锁定 | 模板、范围、强制释放和审计 | 参数值、版本、所有权和最终校验 | 字段级建议，必须跳过人工/安全锁 |
| 设备控制 | 无 | 本站正式控制区发起并等 ACK | 授权维护、应急和跨工位操作 | 鉴权、联锁、下发、超时、ACK 和审计 | 仅提交隐式决策产生的命令意图，不直控设备 |
| 视觉识别 | 展示瓶型/缺陷摘要 | 展示本站识别和证据 | 查询模型结果和审计 | 接收结构化识别结果作为生产事实 | 接收图片、运行瓶型/缺陷模型、保存模型证据 |
| AI 决策 | 全局/当前工位摘要 | 本站建议、锁和执行结果 | 策略、审批和完整审计 | 提供上下文并校验命令意图 | RAG + 实时工具查询 + 字段补丁 + 结果关联 |
| AI 自由问询 | 全局产线范围 | 当前工位优先 | 全局、历史和管理范围 | 提供经鉴权的实时/历史事实 | 会话、路由、工具、RAG、引用和流式回答 |
| AI 选中问询 | 工位/KPI/报警/Three.js 对象 | 文字/参数/设备/物料/Three.js 对象 | 表格行/审计/配置/知识资料 | 按实体 ID 返回最新事实 | 解析统一 `AssistantContext` 并回答选中对象 |
| 知识资料 | 无 | 无 | 上传、审核、拒绝、撤销和发布 | 无知识库职责 | 隔离、解析、治理数据库、文档存储和向量索引 |
| 模拟演示 | 显示中央模拟结果 | 只读模拟；不伪造控制 | 启停和重置生产模拟 | 唯一生产模拟时钟 | 独立可复现视觉/决策/问答模拟并标明来源 |

## 不得越界

- 三个前端都可问 AI，但数字展板只读、小屏不能用聊天绕过正式控制区、后台不能用问答绕过审批。
- 三个前端不得实现独立聊天 UI、会话存储或 AI 客户端；统一依赖 `@bottling/harmony-assistant`，只提供宿主适配器和实体选择。
- Spring Boot 不实现模型调用、提示词、RAG、向量库、文档切分或 AI 会话；只提供生产事实和受控命令接口。
- AI 中枢不直连生产数据库、不直接发布设备 MQTT 命令，也不能解除人工锁或安全联锁。
- 实时回答必须标注数据时间和版本；非实时回答必须显示知识来源和版本。
